# IST Project: Anticancer Peptide Prediction for Lung Cancer

An end-to-end machine-learning research workflow for classifying lung-cancer anticancer peptides (ACPs) using physicochemical descriptors, frozen ESM-2 protein-language-model embeddings, traditional classifiers, sequence-similarity audits, calibration analysis, and residue-level interpretation.

> **Project status:** research prototype with 86 documented analysis steps and publication-oriented outputs. This repository is not a clinical diagnostic system.

## Research overview

The workflow evaluates whether learned ESM-2 representations improve ACP classification over conventional peptide descriptors. It includes:

- quality control and binary-label preparation for 901 peptide sequences;
- physicochemical feature extraction and correlation analysis;
- fixed train/test splitting and cross-validation folds;
- logistic regression, SVM, random forest, and XGBoost baselines;
- frozen `facebook/esm2_t33_650M_UR50D` embeddings and matched classifiers;
- paired bootstrap comparisons, calibration, and decision-curve analysis;
- sequence-redundancy, novelty, nearest-neighbor, and family audits;
- representation-complementarity and feature-fusion experiments;
- hard-case, residue-perturbation, and motif-context interpretation;
- manuscript tables and publication-ready main/supplementary figures.

## Dataset

`data/ACPs_Lung_cancer.csv` contains 901 peptide records with the fields `ID`, `sequence`, and `class`. The project maps `very active` and `mod. active` records to the Active class, and `inactive - exp` and `inactive - virtual` records to the Inactive class.

| Binary class | Peptides |
|---|---:|
| Active | 99 |
| Inactive | 802 |
| Total | 901 |

The dataset is strongly imbalanced; the workflow therefore reports metrics beyond accuracy, including MCC, F1, ROC-AUC, PR-AUC, uncertainty intervals, and calibration measures.

## Environment setup

Python 3.11 was used for the completed workflow.

```bash
python -m venv .venv
```

On Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

The ESM-2 model weights are downloaded from Hugging Face when required. The local model cache is intentionally excluded from Git because it is approximately 2.5 GB and can be regenerated.

## Running the workflow

The analysis is organized as sequential scripts in `scripts/`. Run scripts from the repository root in numerical order. For example:

```powershell
python scripts/01_prepare_data.py
python scripts/02_verify_binary_data.py
python scripts/03_traditional_features.py
```

Later scripts depend on outputs generated by earlier scripts. The completed environment and detailed provenance are recorded in `software_versions.txt` and the result/QC tables.

Some scripts retain the original Windows project path (`E:\postdoc-work\ist-project`) to reproduce the completed run. Change their `PROJECT_DIR` constant if the repository is cloned elsewhere.

- Fixed splits and cross-validation assignments are stored in `derived/`.

- Supplementary copies have a SHA-256 source manifest.
- Downloaded model weights, virtual environments, bytecode, and local run logs are excluded.
